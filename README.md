# Programmazione Lumière

Web app per la gestione della programmazione della Multisala Lumière.

## Struttura

- `index.html` — interfaccia principale
- `css/` — fogli di stile
- `js/` — logica applicativa
- `assets/branding/` — logo e icone dell'app
- `assets/icons/` — icone funzionali e legenda
- `assets/intervals/` — icone degli intervalli
- `assets/rooms/` — grafiche delle sale, organizzate per sala
- `assets/banners/` — risorse utilizzate per i banner

## Note

La riorganizzazione mantiene i percorsi funzionali aggiornati nel codice e non modifica la logica della programmazione.
